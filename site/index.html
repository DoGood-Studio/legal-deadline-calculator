            Kendi yazılımınızda kullanın

            Bu sayfadaki hesapların hepsi açık kaynak lexdays kütüphanesiyle yapılıyor. Bağımlılığı yok, MIT lisanslı. Python ve TypeScript sürümleri aynı test kümesiyle doğrulanır ve aynı sonucu verir.

            GitHub'da kaynak kodu ve dokümanlar

            pip install lexdays

import lexdays
r = lexdays.compute("tr/hmk", "2026-07-30", "P2W")
print(r.deadline)          # 2026-09-08
print(r.explain("tr"))
            npm install lexdays

import { compute } from "lexdays";
const r = compute("tr/hmk", "2026-07-30", "P2W");
r.deadline;                // "2026-09-08"
r.explain("tr");

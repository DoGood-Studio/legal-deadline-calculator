              Kendi yazılımınızda kullanın

              Bu sayfadaki hesapların hepsi açık kaynak lexdays kütüphanesiyle yapılıyor. Bağımlılığı yok, MIT lisanslı. Python ve TypeScript sürümleri aynı test kümesiyle doğrulanır ve aynı sonucu verir.

              GitHub'da kaynak kodu ve dokümanlar

              pip install lexdays

import lexdays
r = lexdays.compute("tr/hmk", "2026-07-30", "P2W")
print(r.deadline)          # 2026-09-08
print(r.explain("tr"))
              npm install lexdays

import { compute } from "lexdays";
const r = compute("tr/hmk", "2026-07-30", "P2W");
r.deadline;                // "2026-09-08"
r.explain("tr");

              Adres çubuğundan hesapla

              Tarayıcınızın arama motoru ayarlarında lexdays'i etkinleştirin ve kısayolunu «süre» yapın. Sonra adres çubuğuna şunu yazın:

              süre 20.10.2026 2 hafta

              Yer imi düğmesi

              Aşağıdaki düğmeyi yer imleri çubuğuna sürükleyin. Herhangi bir sayfada bir tarih seçip yer imine tıklayınca lexdays o tarihle açılır.

              Uygulama olarak kur

              lexdays internet olmadan da çalışır. Telefonda tarayıcı menüsünden «Ana ekrana ekle»yi, bilgisayarda adres çubuğundaki yükle simgesini seçin.

              Bilgilendirme amaçlıdır, hukuki danışmanlık değildir. Kanun, içtihat, mahkeme kararları ve yerel uygulama önceliklidir. Önemli bir süreyi mutlaka kontrol edin.
